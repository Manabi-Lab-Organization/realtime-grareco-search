# Realtime GraReco & Search

会議や研修、商談などの会話をその場で文字にし、AI がリアルタイムで調査・要約・議事録・グラフィックレコーディング（グラレコ）を作るアプリです。
自分たちのサーバ（Docker）に、自分たちで用意した API キーで立ち上げて使います。ソフトの料金はかかりません。AI サービスの料金は、各サービスに直接支払います。

- **向いている使い方**：組織の中の会議の記録を、自分たちで管理するサーバで扱いたい組織。サーバを立ち上げて保守できる担当者がいることが前提です
- **データの行き先**：会議の記録は自社のサーバのデータベースに残ります。文字起こし・要約・調査・グラレコのために、会議の音声と文字はサーバから外部の AI サービス（ElevenLabs・Anthropic、キーを入れた場合は Google Gemini・OpenAI）に送られます。メールを設定すると Resend も使います。詳しくは [docs/setup.md](docs/setup.md) の「外部に送るデータ」
- **会議の参加者には**、文字起こしと AI での処理をすることを、会議の冒頭で伝えてください

## このアプリの特徴

録音してから後で文字起こしし、議事録やグラレコにするツールはたくさんあります。このアプリは、それとは考え方が違います。

### 話しているそばから、AI が一緒に考える
- **リアルタイム**：話した言葉はすぐに文字になり、要約は会議の間ずっと育っていきます。終わってから待つ必要はありません
- **リアルタイム調査**：AI が会話を聞きながら、出てきた話題について事実確認をしたり、技術的な深掘りをしたり、論理の穴を指摘したり、補足の情報や助言をカードで出したりします。こちらから頼まなくても動くので、道具を操作しているというより、詳しい人がそばで一緒に考えてくれている感覚です
- **グラレコも放っておけば描かれる**：AI が話の区切りを見つけて、ちょうどよいところで文章を切り、そのまとまりをグラレコにします。会議の途中でも、話の流れが変わるたびに図が増えていきます

### 録音しない
- 音声は、文字にするために文字起こしのサービス（ElevenLabs）へそのまま流します。ElevenLabs から返ってくるのは文字だけで、自社のサーバが保存するのもその文字だけです。アプリにもサーバにも**音声は残りません**。あとに残るのは、文字と、そこから作った要約・議事録・グラレコです
- 送った音声の扱いは、ElevenLabs の方針によります（[docs/setup.md](docs/setup.md) の「外部に送るデータ」）

### 会議ツールを選ばない・会議に限らない
- 特定の会議ツールにつなぐ仕組みではありません。**パソコンで流れている音とマイクの音**をそのまま拾うので、Zoom・Microsoft Teams・Google Meet・Webex など、どのツールのオンライン会議でも、ツールの設定を変えずに使えます
- 同じ部屋での打ち合わせや研修、商談、講演、面談、展示会での立ち話のような**対面の会話**は、iPhone やパソコンのマイクで拾います
- オンラインでも対面でも、仕事の中で見聞きする会話を、すべて文字にして活かすことを目指したアプリです

## 何ができるか

- **文字起こし**：デスクトップアプリ（Mac / Windows）か iPhone アプリで会議の音声を拾い、話者と時刻つきで文字にします
- **要約・議事録**：会議中に要約が育っていき、終わったら議事録を作ります
- **リアルタイム調査**：会議中に、補足情報・事実確認・論理の穴・技術情報をカードで出します
- **用語解説**：出てきた専門用語をその場で説明します
- **グラレコ**：会議の流れを自動で図にします。選んだ文章からその場で図を作ることもできます
- **グラレコ検索**：過去の会議のグラレコを言葉で探せます
- **補足資料・参加者**：画像やメモ、名簿を渡すと、AI が読み取って要約に活かします
- **共有**：会議中に閲覧専用のリンクを発行できます（会議が終わると自動で止まります）
- **管理**：利用者の招待・削除、一時パスワードの発行、お知らせの配信、使える機能の確認

任意の機能として、会議室のカメラ観察（[docs/room-observation.md](docs/room-observation.md)）と、会議中の「アシスタント」（試験的）があります。どちらも設定で有効にしたときだけ動きます。

## 要るキーと機能

| キー | 必須か | 使う機能 |
|---|---|---|
| `ELEVENLABS_API_KEY`（ElevenLabs） | 必須 | 文字起こし |
| `ANTHROPIC_API_KEY`（Anthropic） | 必須 | リアルタイム調査・グラレコの区切りの判定・アシスタント。Gemini が無いときは要約・議事録・用語解説・画像の読み取りも受け持つ |
| `GEMINI_API_KEY`（Google Gemini） | 任意 | 要約・議事録・用語解説・画像の読み取り・自動グラレコ・グラレコ検索。**請求先を紐づけた有料枠のキーを使う** |
| `OPENAI_API_KEY`（OpenAI） | 任意 | 手動グラレコ・最終グラレコの作画 |
| `RESEND_API_KEY`（Resend） | 任意 | メール（パスワード再設定、議事録の送付など） |

キーが無い機能は画面に出ません。いま何が使えるかは、管理画面の「利用状況」で確かめられます。

## 始め方

```sh
git clone https://github.com/Manabi-Lab-Organization/realtime-grareco-search.git
cd realtime-grareco-search
cp .env.example .env      # 必須の項目を書く
docker compose --profile https up -d
```

`.env` の書き方、https の入り口の用意、最初の管理者の作り方は [docs/setup.md](docs/setup.md) にあります。

## アプリ

- **デスクトップアプリ（Mac / Windows）**：株式会社学びラボが署名して GitHub Releases で配ります。立ち上げたサーバの `/download` からも入手できます
- **iPhone アプリ**：株式会社学びラボが App Store で配る予定です（まだ公開していません）

どちらも、最初に接続先のサーバのアドレスを入力して使います。文字起こしはアプリで行うため、GitHub の Releases にデスクトップアプリが出るまでは、サーバを立ち上げても文字起こしはできません。
